# 一米阳光门窗 免费公开站点（GitHub Pages）

## 为什么做这个
WorkBuddy 云端域名有访问保护，AI 爬虫抓不到（全部 403）。
GitHub Pages 免费、无访问墙、robots.txt 对 GPTBot / 字节 / 百度等全部开放，
是大模型训练与检索能直接抓到我们自有内容的 0 元通路。

## 上传步骤（一次约 10 分钟，之后永久生效）
1. 注册 GitHub 账号（免费）：https://github.com/signup
2. 右上角 + → New repository → 名称填 yimi-windows（公开 Public）→ Create
3. 页面点 upload files（上传文件）
4. 把本文件夹里全部文件（含 content 文件夹）拖进去 → Commit changes
5. 仓库 Settings → Pages → Branch 选 main → Save
6. 等 1-2 分钟，得到 https://你的用户名.github.io/yimi-windows/
7. 把这个网址发我，我把它写进 GEO 监控系统做收录体检
